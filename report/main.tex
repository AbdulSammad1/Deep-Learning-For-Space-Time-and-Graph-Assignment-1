\section*{Response 2}
\textbf{Question:} State the selected moving-average width. Describe what changes in Outputs 2.1--2.3, including the validation comparison of Raw Attention and Attention plus decomposition. Explain why a moving average fits this drift-plus-vibration signal, and why the training-only period check is a fair way to choose the width. Give one case where this bias fails, or name another decomposition and the assumption it would make.

\textbf{Answer:} So I selected moving-average width 41.

In Output 2.1, I tried different widths and checked what happens to the trend and leftover signal. With a small width, the average also follows some of the small vibration, so part of the vibration gets mixed into the trend. At width 17, the leftover standard deviation is 0.578. At width 41, the slow ramp stays more in the trend and the repeating wave is clearer in the leftover, so the leftover standard deviation becomes 1.572.

The Product C example in the figure has a true period of 32 samples. With width 41, the leftover gives a clear peak around this value, while the raw signal does not show it clearly. So in this example, width 41 is doing a better job of separating the slow part and the repeating part.

\begin{figure}[H]
\centering
\includegraphics[width=\textwidth]{figures/output-2-1.png}
\caption{Output 2.1. Different moving-average widths.}
\end{figure}

Output 2.2 was only used for selecting the width. It checks how often the recovered period is within one sample of the real period. The raw signal gets 0.687. The scores for widths 17, 25, 33 and 41 are 0.980, 0.989, 0.993 and 0.998. So I picked 41 because it has the highest recovery score. Its median period error is 0.216 samples. Width 25 has a smaller median error of 0.122, but that was not the rule I was using for selection.

Also, this period check is only done on training data for choosing the width. The true period is not passed to the forecaster when it makes predictions, so I am not giving the model the answer from validation or test data.

For Output 2.3, the useful point is the product-by-product result. On stations 1--3, Raw Attention gives 0.422 / 0.474 / 0.415 for Products A / B / C, and Attention plus decomposition gives 0.284 / 0.337 / 0.287. So it improves all three products. The overall RMSE comparison is shown later in Output 4.1: 0.438 to 0.304 for stations 1--3, and 0.637 to 0.457 for station 4.

A moving average fits this signal because the drift is slow, around 240 samples, while the vibration repeats much faster, around 14 to 36 samples. So width 41 can mostly follow the slow movement and leave the faster repeating part in the leftover. Then the encoder can focus more on that repeating part, while the linear head handles the slow trend.

This idea can fail if the signal suddenly jumps. A moving average can spread that jump over many samples and make it look like part of the vibration. Another option is a Hodrick--Prescott smoother, but that method is also making an assumption: it expects the trend to change smoothly.

\section*{Task 2}
\textbf{Question:} Describe the preprocessing, the model, and the reasons for those choices. Compare the optional external file on and off, on more than one seed, using a time-ordered validation split. State the parameter count and epoch count submitted to the leaderboard.

\textbf{Answer:} So in Task 2, there are 43{,}656 old values and I have to predict the next 168 values, from time\_idx 43657 to 43824. The target is never negative and its average is around 98. It can also change a lot inside one 168-step block. As a very simple baseline, copying only the last value gives RMSE 245.2 on the last four blocks. Copying the last 24 steps gives 175.5, which is better but still quite high.

For preprocessing, I put the past values on log scale. The mean and spread are calculated only from the data available at that stage, so future target values are not used by mistake. The six continuous external columns are scaled in the same way. The four on/off columns are already 0 or 1, so I left them like that.

The future external values for the next 168 steps are also given to the model because these are not target values. I also made a 14-day average for each hour of the day. I used this because one unusual last day should not decide the shape of the whole next week.

The final model is Autoformer. I used moving-average width 25 to split the window into a smooth part and a leftover part. Then FFT correlation is used to find the stronger repeating delays, and the leftover is mixed using shifted copies. So this part is delay mixing, not normal attention.

The model also reads the future external values and the hour-of-day pattern for the main estimate, and then the neural network adds a correction. I used Softplus at the end because the target cannot go below zero. The context length is 336, model width is 32 and there are 2 layers. The training loss is raw squared error because the leaderboard is checking raw RMSE.

For validation, I used the last four separate blocks of 168 steps in time order. I also ran two different random seeds, because I wanted to check that the result was not only coming from one lucky seed.
